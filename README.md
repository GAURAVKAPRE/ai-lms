# SmartLearn – AI Powered Learning Management System

## 🚀 Overview
SmartLearn is a full-stack AI-powered Learning Management System (LMS) that enables instructors to create and manage courses while providing students with intelligent learning assistance features like contextual doubt solving, automated quizzes, and concise content summaries.

The platform also supports secure paid course enrollment using Razorpay payment integration.

---

## 🛠️ Tech Stack
Frontend: React.js  
Backend: Node.js, Express.js  
Database: MongoDB  
Authentication: JWT (JSON Web Tokens)  
AI Features: Vector Search, Embeddings, Semantic Retrieval  
Payments: Razorpay  

---

## ✨ Features

### 👨‍🏫 Instructor Features
- Create and manage courses & lectures
- Upload learning materials (PDFs)
- Track enrolled students

### 👨‍🎓 Student Features
- Secure signup/login authentication
- Enroll in free or paid courses
- Access lecture content and resources

### 🤖 AI Learning Assistant
- Contextual doubt solving from lecture content
- Automated quiz generation
- Concise lecture summaries
- Semantic search using embeddings & vector database

### 💳 Payment Integration
- Razorpay payment gateway integration
- Secure payment verification
- Automatic course enrollment after successful payment

## ▶️ How to Run Locally

1. Clone the repository
2. Install dependencies

npm install

3. Setup environment variables (MongoDB URI, JWT Secret, Razorpay Keys)

4. Start backend

npm run server

5. Start frontend

npm start
